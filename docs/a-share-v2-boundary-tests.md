# A股投资 Agent V2 — Skill 边界验收

## 目的
验证三个 Skill 是独立能力，而不是旧流程的机械拆分。

## 研究与决策
应独立处理：
- 主动寻找新机会；
- 指定公司/行业研究；
- 预期差判断；
- 已有 thesis 验证；
- A股映射；
- 反方/证伪。

失败条件：
- 必须先依赖另一个自建 Skill 才能开始；
- 自己开始决定组合仓位；
- 把涨幅/热点当作机会发现的起点；
- 没有事实/推断/预期边界。

## 组合管理
应独立处理：
- 当前组合风险；
- 新机会仓位；
- 加减仓；
- 多机会竞争资本；
- 再平衡；
- T+1/流动性/真实账户约束。

失败条件：
- 重复完整证券研究；
- 只看单票不看组合；
- 加仓没有新证据/赔率理由；
- 用旧 Memory 猜实时账户；
- 把下单请求等同成交。

## 复盘与学习
应独立处理：
- 单笔交易复盘；
- 阶段性复盘；
- Missed Opportunity；
- 行为偏误；
- 可泛化经验判断。

失败条件：
- 用事后信息重写当时判断；
- 盈利=正确、亏损=错误；
- 单案例直接形成永久规则；
- 自动修改其他 Skill；
- 普通流水全部写入长期 Memory。

## 交叉边界测试

### Case 1
“机器人产业最近有没有尚未充分定价的机会？”
期望：研究与决策即可完成。组合管理不应自动介入。

### Case 2
“我已经持有某股 15%，今天又出了利好，要不要加仓？”
期望：Agent需要真实账户与当前 thesis。主要资本问题由组合管理处理；若利好是否改变 thesis 不清楚，Agent可自行使用研究能力。任何 Skill 都不得指令另一个 Skill。

### Case 3
“过去三个月为什么总是买在主题高潮？”
期望：复盘与学习。只有复盘发现当前方法确有系统缺陷时，输出 Skill improvement candidate，不自动改 Skill。

### Case 4
“查一下我的持仓。”
期望：无需强制加载三个自建 Skill；Agent直接使用实际账户能力。

### Case 5
“买入 100 股某股票。”
期望：若用户只是明确执行已决定的动作，不应为了目录完整性强制运行研究 Skill。Agent遵循当前安全/交易能力规则并确认必要歧义。

## 通过标准
- 三个 Skill 均能独立完成其核心任务；
- 无 Skill→Skill 编排；
- 无重复实现 OpenClaw Memory/Cron/Runtime；
- 无重复实现妙想；
- 交叉任务由 Agent 选择和组合能力；
- 不能明确归属的高频任务才进入“是否新增 Skill”的评估。
