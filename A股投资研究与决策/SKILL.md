# A股投资研究与决策

## 目的
帮助 Agent 回答一个核心问题：**基于当前可获得的信息，我应该相信什么，以及是否存在值得进一步行动的 A 股投资机会？**

本 Skill 是专业方法，不是固定工作流。Agent 是唯一编排者；根据任务自主使用本 Skill、东方财富妙想 Skills、QVeris 或其他获准能力。

## 核心原则
- 变化先于热点：优先寻找现实世界的边际变化，不从涨幅倒推故事。
- 证据先于结论：事实、推断、预期必须分开。
- 预期差先于共识：好公司不等于好机会，正确逻辑不等于当前价格仍有赔率。
- 主动寻找反证：不能只收集支持原判断的信息。
- 可证伪：任何重要投资判断都要说明什么情况意味着自己错了。
- 不确定性必须显式表达；证据不足时允许得出“暂不判断/继续观察”。
- 价格上涨本身不是基本面证据，新闻数量也不是独立证据数量。

## 主动发现机会
当任务要求寻找机会时，从“最近发生了什么重要变化？”开始。

重点观察：
- 政策与监管
- 产业供需、价格、库存、产能、订单与技术路线
- 公司经营、资本开支、产品、客户、管理层与竞争格局
- 全球产业、宏观、商品、科技和供应链变化
- 市场定价、关注度与资金行为

重点寻找：
- Δ Level：水平发生明显变化
- Δ Rate：变化速度发生变化
- Δ Trend：趋势发生拐点
- Δ Relationship：过去稳定的关系发生变化

优先关注多个独立信号指向同一现实变化的情况。不要因为某股票已经大涨才反向制造“早期发现”。

## 研究方法
围绕投资问题建立可检验的因果链：

现实变化 → 供需/竞争格局 → 收入/成本/利润/现金流 → 产业链受益或受损环节 → A股暴露 → 市场预期与当前定价。

研究至少区分：
- FACT：可由可靠来源直接支持的事实。
- INFERENCE：基于事实做出的推断。
- EXPECTATION：对未来的假设或预测。
- UNKNOWN：当前无法确认但可能影响结论的问题。

重要结论应尽可能使用真实、及时、可追溯的数据。需要市场、公司、行业、选股、自选或模拟账户事实时，由 Agent 自主选择当前可用的妙想 Skill；不要凭模型记忆编造实时数据。

## Reality / Expectation / Pricing
投资判断必须同时考虑：
1. Reality：现实实际发生了什么？
2. Expectation：市场大致在预期什么？
3. Pricing：当前价格可能已经反映了多少？

寻找的不是“利好”，而是三者之间仍有经济意义的差异。

必须考虑：
- 信息是否已经广泛传播；
- 股价是否已经提前反映；
- 市场一致预期是否已经改变；
- 潜在收益是否足以补偿判断错误、时间和风险。

## 反方与证伪
在形成较强结论前，主动回答：
- 最有力的反方解释是什么？
- 哪个关键事实如果不成立，会破坏因果链？
- 哪些数据可能只是相关而非因果？
- 有没有基准率、周期或一次性因素被忽略？
- 什么未来观察结果会强化、削弱或证伪判断？

高置信度不能仅来自更多同方向材料。

## 输出
根据任务需要组织，不强制固定模板，但应尽量包含：
- 当前判断
- 关键事实与来源
- 核心因果链
- 市场预期/定价判断
- 支持证据
- 反方证据
- 关键未知项
- 证伪条件
- 还需要验证什么

不要因为使用本 Skill 就自动产生买卖动作。投资研究结论与资本配置是不同问题；是否调整组合由 Agent 根据任务和可用能力另行判断。
