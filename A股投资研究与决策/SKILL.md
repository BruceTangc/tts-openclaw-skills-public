# A股投资研究与决策

## 使命
帮助 Agent 回答：**基于当前可获得的信息，我应该相信什么？这里是否存在值得投资的 A 股机会？**

这是专业能力，不是固定工作流。Agent 是唯一编排者。不要调用、调度或强制跳转到其他 Skill；完成当前任务后把结果交还 Agent。

## 何时使用
适用于：
- 主动寻找尚未充分定价的新机会；
- 研究指定公司、行业、主题、政策或事件；
- 验证已有投资逻辑是否仍成立；
- 判断利好/利空是否已被预期或定价；
- 比较若干投资机会的研究质量与赔率；
- 回答“值不值得进一步研究/投资”。

不适用于：
- 主要问题是已有组合怎么分配资本、仓位多大、是否再平衡；
- 主要问题是复盘过去判断并提炼经验；
- 仅查询行情/财务/新闻/自选/账户，Agent 可直接使用相应能力。

## 不可妥协的投资纪律
1. **变化先于热点**：优先寻找现实世界的边际变化，不从涨幅榜倒推故事。
2. **证据先于结论**：FACT、INFERENCE、EXPECTATION、UNKNOWN 必须分开。
3. **预期差先于共识**：好公司不等于好投资；正确逻辑不等于当前价格仍有赔率。
4. **因果优于相关**：价格、资金、新闻热度可以是验证信号，不能自动成为基本面原因。
5. **主动寻找反证**：高置信度不能来自重复的同方向材料。
6. **可证伪**：重要判断必须说明什么事实会使其削弱或失效。
7. **允许不行动**：证据不足、赔率不清楚或关键事实无法验证时，WAIT/NO CONCLUSION 是有效结果。
8. **时间一致性**：不得使用后来信息重写“当时已经发现”的历史。

## 主动发现机会
当任务是寻找机会时，从“最近发生了什么重要变化？”开始，而不是“今天什么最热门？”

扫描：政策/监管；产业供需、价格、库存、产能、订单、技术路线；公司经营、产品、客户、资本开支、管理层、竞争格局；全球产业、宏观、商品、科技、供应链；信息扩散与市场注意力；市场定价和资金行为。

寻找：
- Δ Level：水平显著变化；
- Δ Rate：变化速度变化；
- Δ Trend：趋势拐点；
- Δ Relationship：过去稳定关系失效或重构。

优先研究多个独立来源或独立机制共同指向同一现实变化的信号。重复转载不算独立证据。

发现阶段先形成值得回答的问题：
**异常 → 为什么 → 是否持续 → 谁受影响 → 利润如何传导 → A股谁真正暴露 → 市场知道多少。**

若要声称“提前发现”，必须有当时时间证据。没有记录只能说事后识别，不得补写 first_seen。

## 研究与验证
围绕问题建立可检验因果链：

**现实变化 → 供需/竞争格局 → 收入/成本/利润/现金流 → 产业链受益/受损 → A股真实暴露 → 市场预期 → 当前定价。**

优先回答：
- 变化是真实还是噪声？
- 持续时间和经济量级多大？
- 谁真正获得利润，而不是谁概念最相关？
- A股标的收入/利润暴露是否实质？
- 逻辑依赖哪些关键假设？
- 哪些证据来自同一原始来源，不能重复计权？

## 证据协议
重要证据至少在推理中明确：
- claim：支持什么；
- source：来源；
- observed_at / period：观察时间与覆盖期；
- type：FACT / INFERENCE / EXPECTATION / UNKNOWN；
- direction：支持 / 反对 / 中性；
- freshness：是否仍足够新；
- materiality：是否足以改变判断。

来源优先：一手/官方/公司公告/真实经营和市场数据 > 高质量可核验二手资料 > 搜索摘要、媒体转述、社区观点。后者主要作为线索或注意力/预期证据。

涉及实时行情、公司、行业、选股、自选等事实时，由 Agent 根据当前可用能力自主选择妙想或其他获准能力。不要硬编码妙想内部 API，也不要用模型记忆编造实时数字。工具失败、结果为空或数据过期时必须显式说明。

## Reality / Expectation / Pricing
任何“值得投资”的判断都尽量回答：

**Reality**：现实发生了什么？方向、幅度、速度、持续性如何？

**Expectation**：市场大致已经相信什么？一致预期、主流叙事和关注度是否改变？

**Pricing**：当前价格可能反映了多少？价格、估值、拥挤和事件反应是否说明预期已经进入价格？

寻找的是三者之间仍有经济意义的差异，而不是简单寻找“利好”。

## A股映射
必须区分：
- 业务相关 ≠ 利润相关；
- 概念标签 ≠ 实质暴露；
- 收入受益 ≠ 利润受益；
- 行业增长 ≠ 单家公司能获得超额收益。

优先确认收入/利润暴露、市占率、竞争地位、产能兑现、客户/订单、估值与当前预期，以及可能受损的反向因素。选股结果只是候选集，不是投资结论。

## 反方与证伪
形成较强判断前，构建最有力的反方：
- 核心变化是否一次性？
- 是否存在替代解释？
- 是否把相关性当因果？
- 利润会否被竞争、降价、成本或资本开支吞噬？
- 市场是否已经充分知道？
- 基准率/历史周期是否冲突？
- 哪个关键事实最可能证明我们错？

不要为了形式罗列弱反方。

## 投资判断（判定表）

研究结束**必须**落到下表唯一的格子，不允许自创中间态。先判证据等级，再判赔率，交点即结论。

### 第一步：定证据等级（E 级）

| 级别 | 硬定义（满足全部） |
|:--|:--|
| **E1 强** | ① ≥2 条**独立原始来源**（非转载、非同一新闻稿）② 因果链每一环都有可核验数据 ③ 关键假设可直接观测验证 |
| **E2 中** | ① 独立来源凑不满 2 条，或 ② 因果链中有一环靠 INFERENCE 补，或 ③ 关键假设只能间接验证 |
| **E3 弱** | ① 只有 1 条来源，或 ② 主要靠叙事/概念/研报观点，或 ③ 关键假设无法验证 |
| **E0 无效** | 关键数据 UNKNOWN，或数据过期（行情 >1 交易日、财务 >1 季报期） |

**独立来源判定**：同一原始稿件被多家转载算 **1 条**；来源之间共享同一信息源或同一利益方，算 1 条。

### 第二步：定赔率（R 级）

| 级别 | 硬定义 |
|:--|:--|
| **R1 高** | 乐观情形收益 ≥ 保守情形损失的 **2 倍**，且估算有可写下的估值锚（PE band / PB / 现金流区间） |
| **R2 中** | 收益/损失比在 **1～2 倍**之间 |
| **R3 低** | 收益/损失比 **< 1 倍**，或无法给出任何估值锚 |
| **R0 未知** | 无法估算下行，或标的不在能力可覆盖范围 |

### 第三步：查表得结论

|  | R1 高赔率 | R2 中 | R3 低 / R0 未知 |
|:--|:--|:--|:--|
| **E1 强** | 有吸引力且仍有预期差 | 逻辑成立但定价不足 | 值得继续验证（等价格） |
| **E2 中** | **值得继续验证（可交组合管理评估 PROBE）** | 值得继续验证 | 不行动 |
| **E3 弱** | 值得继续验证（仅信息跟踪） | 不行动 | 不行动 |
| **E0 无效** | 证据不足，结论 UNKNOWN | 证据不足 | 证据不足 |

### 强制规则（违反视为本 Skill 执行失败）

1. **E0 不得给出「有吸引力」结论**，无论 R 多高。
2. **E3 + R3 直接判「不行动」**，禁止写成「值得继续跟踪观察」糊过去——这是最常见的安全退化。
3. 「值得继续验证」**必须写清三件事**：验证什么、什么时候能看到、看到什么算成立。写不出来就降级为「不行动」。
4. 「证据冲突，暂不判断」**只在两条同等级来源给出相反方向事实时**允许使用。信息不全不算冲突，那属于 E0/E3。
5. 每个结论必须能回答：**我错在哪里会最先暴露？** 答不出，结论降一级。
6. 输出结论时必须标出 **E级/R级**（如 `E2/R1`），便于复盘核对判断质量。

### 何时必须给结论（禁止无限拖延）

- 同一标的连续 **3 个交易日**给出「值得继续验证」且无实质升级 → 第 4 次必须给「有吸引力」或「不行动」。
- 同一标的已有持仓且核心 thesis 被削弱 → 不得停在「证据冲突」，必须给「逻辑被削弱」并交还 Agent 转组合管理。
- 用户直接问「值不值得买」时，不得用「还需研究」代替回答：要么给结论 + E/R 等级，要么明说卡在哪一条 UNKNOWN。

## 输出最低要求
若 workspace 已安装 A股投资 Agent V2 工作制度，正式用户汇报必须遵循 `A股投资Agent工作制度/OUTPUT-TEMPLATES.md`，本 Skill 不自行发明另一套格式。研究内容至少要能支持模板中的：当前结论、关键 Reality、核心因果链、A股映射、Expectation/Pricing、支持证据、最强反方、UNKNOWN、证伪条件和下一验证点。

完成后把研究结论与关键证据交还 Agent。不要自行编排其他 Skill，也不要由本 Skill 直接执行交易；但 Agent 获得结论后应自主判断是否需要进一步进行组合管理并使用实际安装的妙想模拟交易能力执行，而不是默认研究结束即停止行动。
