# 投资复盘与学习

## 使命
帮助 Agent 回答：**过去的投资判断和行为质量如何？结果为什么发生？哪些经验真正值得影响未来？**

这是学习能力，不是行情总结，不是绩效表，也不是自动修改其他 Skill 的机制。Agent 是唯一编排者。

## 何时使用
适用于：单笔/多笔投资复盘；日周月阶段复盘；判断为什么对/错；Missed Opportunity；检查发现、研究、组合、执行的系统性问题；判断什么值得进入长期 Memory。

不适用于：当前研究新机会；当前主要决定组合怎么调；单纯记录今天发生了什么。

## 第一原则：恢复当时的信息集
先尽可能恢复决策时点：当时知道什么、不知道什么、证据是什么、来源是否可得、市场预期、thesis/反方/证伪条件、为什么行动或没行动、当时组合和风险约束。

禁止用后来信息假装当时已经知道。无法恢复时降低复盘结论置信度。

## 决策质量与结果分离
强制区分：
- 好决策 + 好结果；
- 好决策 + 坏结果；
- 坏决策 + 好结果；
- 坏决策 + 坏结果。

盈利不自动证明方法正确；亏损不自动证明方法错误。将可控过程与随机性、突发事件和市场环境分开。

## 复盘链条
按实际任务检查：
**发现 → 研究 → 预期/定价 → 投资判断 → 资本配置 → 执行 → 后续管理 → 退出 → 结果。**

不机械遍历全部环节，只检查与结果有关的环节。

## 错误分类
- **信息错误**：事实错误、数据过期、来源不可靠、关键数据未查；
- **发现错误**：重要变化发现过晚、遗漏或被噪声吸引；
- **因果错误**：相关当因果、利润传导或持续性错误；
- **映射错误**：产业逻辑成立但股票暴露不实质；
- **预期错误**：误判共识、priced-in 或拥挤；
- **赔率错误**：方向可能正确但价格/回报不足；
- **组合错误**：仓位、集中度、相关风险或机会成本错误；
- **执行错误**：下单、数量、价格、重复执行或状态确认问题；
- **管理/退出错误**：证伪后拖延、无新证据加仓、过早退出；
- **行为偏误**：确认偏误、锚定、过度自信、后见之明、损失厌恶、处置效应等；
- **过程无明显错误**：主要由合理范围的随机性/不可预见事件导致。

不要为了“必须学到东西”强行制造错误。

## 发现质量
对于主动发现：最早何时出现可观察信号？Agent 实际何时发现？提前量是真信息优势还是事后叙事？初始信号是否可重复识别？假阳性如何？是否因追热点错过更早现实变化？

没有当时记录，不得声称提前发现。

## Missed Opportunity
问：当时是否存在可获得有效信号？为什么没看到/没研究/没行动？是信息不可得、注意力、筛选、证据门槛、资本约束还是合理拒绝？新增规则会提高未来发现率还是制造噪声？

一个事后大涨案例不足以证明系统必须新增规则。

## 行为偏误
有具体行为证据时检查：只找支持 thesis 的证据；锚定成本/目标/旧预测；近期成功导致过度自信；亏损后拒绝证伪；后见之明；把随机连胜当能力；因后悔规避而不行动或乱行动。不要机械贴标签。

## 学习门槛
经验进入长期学习前问：
1. 适用条件是否明确？
2. 是否有多个结果或足够强机制证据？
3. 是否解释“为什么”？
4. 是否可能只是市场阶段/样本偶然？
5. 新规则会减少错误还是增加过拟合？
6. 是否与更强原则冲突？

允许“暂不形成长期规则，继续观察”。

## 经验分级
- **Case-specific**：只解释本案例；
- **Candidate lesson**：可能可复用，需要更多样本；
- **Durable lesson**：机制清晰、跨案例有效，可进入长期 Memory；
- **Process fix**：工作制度/流程缺陷候选；
- **Skill improvement candidate**：专业方法可能需调整，只提出候选，不直接修改 Skill。

## 与 OpenClaw Memory 的边界
本 Skill 判断“值得学什么”，不自己实现 Memory。

适合长期保存：经验证稳定原则、多次出现错误模式、长期有效个人约束/决策、后续工作必须知道的重要结论。

不宜直接升级长期记忆：一次性行情、未验证猜测、普通日内流水、仅因一次盈亏产生的规则。日常事实优先留在日记忆；是否进入长期 Memory 由 Agent 按当前 OpenClaw 记忆机制决定。

## 输出最低要求
根据任务包含：复盘范围与时点、当时信息集、当时判断/资本动作、后续真实结果、Decision Quality 与 Outcome 分离、主要正确点、主要错误及层级、行为偏误（有证据才写）、Missed Opportunity、Case/Candidate/Durable lessons、不应泛化因素、值得长期 Memory 的内容、下次具体改变什么。

完成后停止并把结果交还 Agent。不得自动修改其他 Skill，也不得用事后结果重写历史。
