# 投资复盘与学习

## 目的
帮助 Agent 回答：**过去的投资判断和行为质量如何，结果为什么发生，哪些经验真正值得影响未来？**

复盘不是行情总结，也不是按盈亏评判对错。Agent 是唯一编排者；需要历史记录、市场事实或账户结果时，由 Agent 自主获取。

## 第一原则：恢复当时的信息集
任何复盘都应尽可能回到决策发生时：
- 当时已经知道什么？
- 当时不知道什么？
- 当时有哪些证据？
- 当时的预期是什么？
- 当时为什么采取或没有采取行动？

禁止用后来才出现的信息假装当时已经知道。

若无法恢复当时的信息集，应明确降低复盘结论置信度。

## 决策质量与结果分离
必须区分：
- 好决策 + 好结果
- 好决策 + 坏结果
- 坏决策 + 好结果
- 坏决策 + 坏结果

盈利不能自动证明决策正确，亏损不能自动证明决策错误。随机性、市场环境和不可预见事件必须与方法质量分开。

## 错误归因
优先定位错误发生在哪一层，而不是笼统写“判断失误”：
- 信息：事实错误、数据过期、来源不可靠
- 发现：重要变化发现过晚或漏掉
- 因果：把相关性当因果，传导链错误
- 预期：误判市场共识或 priced-in 程度
- 映射：产业逻辑正确但 A 股标的映射错误
- 赔率：方向可能正确但价格/风险收益不合理
- 组合：仓位、集中度、相关暴露不合理
- 执行：实际交易与原决策不一致
- 退出：证伪后未退出，或过早放弃仍成立的逻辑
- 行为偏误：确认偏误、锚定、过度自信、后见之明、损失厌恶等

允许结论为“主要由随机性导致，暂不修改方法”。

## 遗漏机会
复盘不仅看做过的交易，也看没有做的事情。

对重要遗漏问：
- 当时是否已经存在可观察信号？
- 为什么 Agent 没有注意到？
- 是信息不可得、注意力不足、方法缺陷还是合理过滤？
- 如果增加规则，会提高未来发现率还是制造更多噪声？

不得为了一个事后大涨案例随意新增规则。

## 学习门槛
只有满足以下特征的经验才适合长期保留：
- 能明确描述适用条件；
- 有证据支持，不只是一次结果；
- 能解释为什么具有可迁移性；
- 不与更强证据冲突；
- 不把偶然市场结果包装成规律。

优先形成小而明确的经验，而不是不断增加复杂规则。

## 与 Memory 的边界
本 Skill 负责判断“学到了什么”，不自行实现 Memory 系统。

当 Agent 判断某条经验值得长期保留时，应使用 OpenClaw 当前原生记忆机制保存；日常流水、一次性噪声和未经验证的猜测不应轻易升级为长期经验。

## 输出
复盘结果按任务需要包含：
- 当时的信息集
- 当时的判断与行动
- 后续实际结果
- Decision Quality 与 Outcome 的分离判断
- 主要正确点
- 主要错误及归因
- 遗漏机会（如有）
- 可复用经验
- 不应泛化的偶然因素
- 值得长期记忆的内容
- 下一次遇到类似情形应改变什么

复盘结束后将结果交还 Agent；本 Skill 不自动修改其他 Skill 的规则。
