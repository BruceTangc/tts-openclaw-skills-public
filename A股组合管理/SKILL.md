# A股组合管理

## 目的
帮助 Agent 回答：**在已有持仓、现金、风险和其他机会共同存在的情况下，资本应该如何配置？**

本 Skill 不负责发现所有投资机会，也不代替投资研究。Agent 是唯一编排者，并自主决定何时查询真实账户、行情或其他事实。

## 核心原则
- 好投资逻辑不自动等于应该买入。
- 买入判断不自动等于应该重仓。
- 每次调整必须从整个组合而非单只股票视角判断。
- 仓位反映的是风险调整后的判断，不是情绪或信念强度。
- Capital follows evidence：新增风险暴露需要与新增或更强证据相匹配。
- 不因亏损本身补仓，不因盈利本身加仓。
- 不把“长期看好”当作忽略风险和证伪的理由。

## 组合视角
在资本决策前，根据任务重要性检查：
- 当前真实持仓与可用资金
- 单票和行业/主题集中度
- 多个持仓是否暴露于同一底层风险
- 当前机会相对组合中其他机会的吸引力
- 预期收益、潜在损失和不确定性
- 流动性、交易成本与可执行性
- A股 T+1 等实际交易约束
- 已有投资假设是否仍然成立
- 是否存在更好的“不交易”选择

涉及当前账户事实时，应由 Agent 使用实际可用的账户/行情能力获取最新数据，不得根据旧记忆猜测持仓、现金或可卖数量。

## 仓位变化纪律
### 建仓 / Probe
当判断尚有较大不确定性但值得用有限资本验证时，可考虑小规模暴露。仓位必须允许判断错误而不对组合造成不可接受损害。

### 加仓
加仓必须能回答：
**与上一次资本决策相比，出现了什么新的、独立且重要的证据？**

仅有以下情况不足以支持加仓：
- 股价下跌；
- 自己更有信心；
- 更多媒体重复同一信息；
- 已经亏损所以想摊低成本；
- 已经盈利所以追加强势。

### 持有
持有也是主动决策。需要确认原始逻辑、赔率和组合机会成本仍然合理。

### 减仓 / 退出
优先考虑：
- 核心假设被削弱或证伪；
- 预期差明显收敛；
- 风险收益恶化；
- 组合暴露过度集中；
- 出现明显更优的资本用途；
- 流动性或市场结构使原风险预算不再合理。

不要为了“等回本”延迟退出。

## 决策质量
资本决策至少应能说明：
- 为什么现在需要改变仓位，而不是保持不动？
- 哪些事实发生了变化？
- 当前最大风险是什么？
- 如果判断错误，损失路径是什么？
- 仓位大小为什么与不确定性相匹配？
- 什么情况会触发下一次重新评估？

如果关键账户事实、交易约束或投资依据无法确认，应降低动作强度或不行动，而不是补齐想象。

## 执行边界
本 Skill 提供组合与仓位决策方法，不实现交易接口。

如果 Agent 最终决定执行，应由 Agent 使用当前实际安装且可用的交易能力（例如 mx-moni），并以真实工具返回结果为准。不得假定某个版本具有未实际验证的交易动作。

## 输出
按任务需要说明：
- 当前组合判断
- 建议动作或 NO ACTION
- 关键依据
- 组合影响
- 主要风险
- 仓位/风险预算逻辑
- 触发重新评估的条件
- 尚未确认的信息
