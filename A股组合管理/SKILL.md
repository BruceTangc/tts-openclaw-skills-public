# A股组合管理

## 使命
帮助 Agent 回答：**在已有持仓、现金、风险约束和其他机会同时存在时，资本应该如何配置？**

这是资本配置能力，不是交易接口，不是日程流程。Agent 是唯一编排者；本 Skill 不调用其他 Skill。

## 何时使用
适用于：当前持仓调整、新机会投入多少、建仓/加仓/减仓/退出、集中度与相关暴露、现金比例、多机会竞争资本、再平衡、流动性与交易约束。

不适用于：主要是发现/研究新机会；主要是事后复盘；只想查余额/持仓。

## 核心纪律
1. **证券判断与资本决策分离**：看对方向不等于应该买；可以买不等于应该重仓。
2. **组合优先**：任何动作考虑现有组合，而不是孤立看一只股票。
3. **Capital follows evidence**：增加风险暴露必须有新增或更强的独立证据/赔率支持。
4. **风险不只是波动**：同时考虑 thesis、预期/估值、集中度、相关暴露、流动性、执行和制度约束。
5. **NO ACTION 有效**：没有足够优势时，现金和不交易都有价值。
6. **不为成本价服务**：成本价不是基本面，不因“等回本”延迟退出。
7. **先核实账户事实**：真实持仓、现金、可卖数量、成交状态必须用当前数据。

## 决策前组合快照
按任务重要性确认：当前持仓/数量/成本/现价/可卖数量、现金、单票权重、行业/主题/产业链暴露、共享底层风险、各 thesis 状态、机会成本、流动性/交易成本/T+1 等约束、未确认订单或执行状态。

账户事实需要最新数据时，由 Agent 自主使用当前实际安装的账户/交易能力。不得把 Memory 中旧持仓当实时真值。

## 风险预算
仓位大小随以下因素变化，而不是套固定百分比：证据质量与独立性、可证伪程度、预期差和剩余赔率、潜在损失路径、时间维度、流动性、与其他持仓的相关风险、组合总风险、替代机会。

高置信度不等于无限仓位；无法可靠估计下行时更保守。

## 资本动作（判定表）

**先过前置门，再查动作表。** 前置门不过，唯一合法输出是 `NO ACTION (BLOCKED)`。

### 前置门（任一为真则 BLOCKED，禁止进入动作表）

| 门 | 判定 | 不过时输出 |
|:--|:--|:--|
| **G1 账户事实** | 本轮已调用账户/持仓查询能力并拿到**当日**真实返回 | `NO ACTION (BLOCKED: 账户未核实)` |
| **G2 行情新鲜度** | 标的当前价来自当日或最近交易日收盘 | `NO ACTION (BLOCKED: 行情过期)` |
| **G3 执行可行性** | T+1 / 可卖数量 / 停牌 / 涨跌停 / 交易时段已确认 | `NO ACTION (BLOCKED: 执行条件未知)` |
| **G4 同向挂单** | 无未确认的同方向在途订单 | `NO ACTION (BLOCKED: 在途订单未确认)` |

**G1 是硬要求**：不得用 Memory 里的旧持仓代替实时查询。查询失败也要如实写「账户 UNKNOWN」并 BLOCKED，而不是基于记忆继续推理。

### 动作表：研究结论 × 组合状态 → 动作

研究结论取 `A股投资研究与决策` 输出的 E/R 等级。

| 研究结论 | 无持仓 | 已持仓，thesis 完好 | 已持仓，thesis 削弱 |
|:--|:--|:--|:--|
| **E1/R1 有吸引力** | **BUY**（按风险预算定仓） | **ADD**（须有新独立证据） | **REDUCE 优先** |
| **E1/R2 定价不足** | NO ACTION（等价格）/ PROBE | HOLD | REDUCE |
| **E2/R1** | **PROBE**（小仓验证） | HOLD 或小幅 ADD | NO ACTION（不加） |
| **E2/R2** | NO ACTION | HOLD | REDUCE |
| **E3 任意 / E0** | NO ACTION | HOLD | EXIT |
| **逻辑被证伪** | / | **EXIT** | **EXIT** |

### 各动作的准入条件（必须逐条满足，缺一不可）

| 动作 | 准入条件 |
|:--|:--|
| **NO ACTION** | 满足以下任一条：优势不足（E3/R3）、关键事实 UNKNOWN、赔率不清、已有暴露已足够、前置门 BLOCKED |
| **PROBE** | ① 研究结论为 E2/R1 或 E1/R2 ② 金额 ≤ 组合净值 **3%** ③ 明确写出「什么结果算验证成功/失败」 ④ 明确写出验证期限（≤10 个交易日） |
| **BUY** | ① E1/R1 ② 单票权重 ≤ 风险预算上限 ③ 写出估值锚 ④ 写出证伪条件 |
| **ADD** | ① 现有持仓 thesis 未削弱 ② **出现与上次资本决策相比新的、独立、重大的证据或赔率改善** ③ 加仓后单票权重仍 ≤ 上限 |
| **HOLD** | ① 账户已核实 ② thesis 未实质削弱 ③ 赔率仍可接受 ④ 仓位仍符合风险预算 ⑤ 无更优资本用途 |
| **REDUCE** | 满足任一条：预期差收敛、风险收益下降、集中度超限、thesis 削弱、出现更优用途、流动性/结构改变风险预算 |
| **EXIT** | 满足任一条：核心假设证伪、原持有理由消失、赔率恶化到 R3、风险不可接受 |

### 反退化硬规则

1. **ADD 的「新证据」必须能指出是哪条数据、什么时候取得、与上次决策相比新在哪。** 股价下跌、摊低成本、主观更有信心、重复新闻、强势上涨——**均不能单独构成 ADD 理由**，出现任一即驳回。
2. **PROBE 不是 BUY 的缩水版**：必须有验证期限和验证标准，到期未验证成功按失败处理，不得默默转成 HOLD。
3. **HOLD 必须每轮重新核实账户**，不得因为「上次是 HOLD」就跳过 G1。
4. **模拟账户同样适用全部门禁**。模拟属性不降低仓位纪律要求，只放宽「允许试错」——试错也必须有依据、有期限、可归因。
5. **不允许因为「避免任何亏损」无限 NO ACTION**：连续 5 个交易日 NO ACTION 且期间市场出现 E1/R1 机会 → 必须在下一次汇报中说明为什么错过。

## 多机会竞争资本
比较证据质量、预期差、风险调整后赔率、时间窗口、与组合的相关性、流动性、证伪清晰度和机会成本。无法可靠区分时可保留现金，不制造虚假精确排序。

## 执行前
任务确实要求执行时至少确认：账户状态最新；动作与刚形成的资本决策一致；数量/价格/方向无歧义；T+1/可卖数量/市场状态允许；没有尚未确认的同方向执行；当前交易能力实际支持该动作。

本 Skill 不假设 mx-moni 固定版本或固定动作集合，以当前安装版本实际能力和真实返回为准。

## 执行后
若 Agent 实际执行：不把“请求已发送”当“已成交”；记录真实返回；状态不明确先查询核对，避免重复下单；后续判断以确认后的账户状态为准。

## 输出最低要求
若 workspace 已安装 A股投资 Agent V2 工作制度，正式用户汇报必须遵循 `A股投资Agent工作制度/OUTPUT-TEMPLATES.md`；涉及资本动作时使用资本决策模板，不自行发明格式。内容至少要能支持：当前组合/关键暴露、动作（NO ACTION / PROBE / BUY / ADD / HOLD / REDUCE / EXIT）、为什么现在、仓位/风险逻辑、组合影响、最大风险、约束与未知项、重新评估/减仓/退出条件，以及真实执行状态。

完成后把资本决策交还 Agent。不要自行编排其他 Skill。


## 模拟账户试错原则
若 Agent 已确认当前执行环境为妙想模拟账户，可允许有依据、有限仓位、可复盘的试错。模拟亏损本身不是系统失败；无依据交易、重复同类错误、无法归因、复盘后不改变行为，才是需要重点纠正的问题。模拟属性不等于取消风险管理：仓位、T+1、流动性、组合暴露和执行状态仍应真实处理，以免学到无法迁移到真实市场决策的坏习惯。
