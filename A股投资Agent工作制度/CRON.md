# A股投资 Agent 全天 Automations/Cron 设计

Cron 只负责**唤醒并定义时点目标**。不要在 Cron prompt 复制 Skill 方法、工具 API 或完整检查表。

所有时点都遵循 AGENTS.md 的统一恢复/交接协议：恢复 ACTIVE → 读取增量 → 工作 → Worklog → 更新 ACTIVE。

> 以下时间为 A 股交易日的工作节奏候选。安装前应与现有 OpenClaw Automations 合并，不应盲目重复创建。

## 08:45 — 盘前恢复与隔夜变化

Prompt:
```
恢复投资 Active Context 和最近相关 memory，确认昨日未完成事项。检查自上次工作以来可能改变现有 thesis、组合风险或产生新投资机会的重大隔夜变化。优先处理高影响变化；需要实时事实时使用实际可用数据能力验证。无重大变化则记录 NO MATERIAL CHANGE。完成后写 worklog 并更新 Active Context。
```

目标：从昨天接上今天，不是每天重新建立世界模型。

## 09:20 — 竞价前验证

Prompt:
```
从当前 Active Context 继续。只检查盘前新增信息和需要在开盘前确认的高优先级事项，更新机会/thesis/组合关注点。不要重复 08:45 已完成的研究。无重要变化则简记。完成后更新交接状态。
```

## 09:40 — 开盘验证

Prompt:
```
继续今天已有工作，检查开盘后的价格/成交/市场反馈是否提供了新的验证或反证，以及是否出现新的重大异常。市场行为是证据之一，不得用价格本身替代基本面因果。只有资本问题确实出现时才评估组合动作。完成后记录增量并更新 Active Context。
```

## 11:30 — 午间收束与研究

Prompt:
```
恢复上午最新状态。总结上午真正改变判断的增量，继续处理 Active Context 中最高价值的未解决研究问题；检查是否有 thesis 被强化、削弱或证伪，以及组合是否出现需要下午处理的风险。避免重新扫描已完成事项。完成后更新 worklog 和 Active Context。
```

## 13:30 — 午后增量检查

Prompt:
```
从午间状态继续，只处理午后新增信息、待验证事项和组合风险变化。优先关注会改变今日决策的问题，不为完成定时任务强行制造机会或交易。完成后更新交接状态。
```

## 14:30 — 决策窗口

Prompt:
```
基于今天已经积累的研究和最新真实账户/市场状态，检查是否存在需要在收盘前处理的资本决策。不要从头研究市场；重点处理 Active Context 中已经成熟或风险发生变化的事项。账户或关键事实不确定时 NO ACTION。执行状态必须以真实工具返回为准。完成后记录理由与状态。
```

## 15:10 — 收盘状态固化

Prompt:
```
收盘后从今日 Active Context 继续，确认收盘结果和任何未确认执行状态。记录今天哪些 thesis/机会/组合状态真正发生变化，关闭已失效事项，保留需要晚间继续研究的问题。不要做深度复盘；先把事实和状态固化，完成 worklog 与 Active Context。
```

## 20:30 — 深度研究与学习

Prompt:
```
恢复今天完整投资工作上下文。优先完成白天未解决且仍重要的深度研究；对今天有学习价值的判断、交易或遗漏做必要复盘，区分决策质量与结果。只将经验证的 durable lesson 候选升级到长期记忆；普通日内流水留在 daily memory。最后整理 Active Context，使下一交易日能够直接继续。
```

## 周末 — 周度复盘与研究议程

Prompt:
```
基于本周 daily memory、Active Context 和真实结果做周度复盘：检查发现质量、研究判断、组合管理、执行、Missed Opportunities 和重复错误。区分随机结果与方法问题，提炼 Candidate/Durable lessons，并整理下周仍有效的 thesis、开放问题和研究优先级。不要因单一案例修改长期规则。
```

## 为什么没有更多 Cron
时间点不是越多越好。只有当一个时点提供新的信息结构或决策窗口时才值得唤醒。若实测某时点长期只有 NO MATERIAL CHANGE，应考虑降低频率，而不是让模型机械工作。
