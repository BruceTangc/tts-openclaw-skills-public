# A股投资 Agent 全天 Automations/Cron 设计

Cron 只负责**最低巡检频率和时点目标**，不是买卖时间表。V2 是市场自适应投资 Agent，不预设长期或短线风格；资本决策由 Reality / Expectation / Pricing、证据变化、组合风险和真实账户状态驱动。

所有时点遵循 AGENTS.md：恢复 ACTIVE → 读取增量 → 工作 → 固定模板输出 → Worklog → 更新 ACTIVE。

## 08:45 — 盘前恢复与隔夜变化
恢复昨日状态，检查隔夜公告、外围、产业和公司变化以及未完成研究。若已经形成需要处理的资本问题，可立即评估，不等待下午。

## 09:27 — 集合竞价结果验证
读取竞价结果和盘前新增信息，只处理相对 08:45 的增量。竞价是市场预期/定价证据之一，不自动等于基本面变化。

## 09:40 — 开盘后现实验证
验证竞价信号、开盘后的价格/成交反馈和新增事实。若资本条件已经改变，立即评估组合动作，不等待固定尾盘节点。

## 10:30 — 上午趋势与机会变化检查
检查开盘后新形成的主线、异常、产业/公司事实和市场重新定价。重点比较 Reality / Expectation / Pricing 是否发生实质变化，不重复开盘结论。

## 11:15 — 上午最后检查与交接
处理上午仍重要的新增信息、thesis 变化和组合风险，为午间留下明确 handoff。若需要资本动作且真实执行条件满足，可以当时评估；否则 NO ACTION。

## 13:30 — 午后重新定价检查
检查午间新增信息、上午主线延续/反转以及午后重新定价，只处理相对 11:15 的增量。重大变化可立即触发资本重新评估。

## 14:30 — 尾盘风险与未完成事项检查
检查当天仍未解决但可能影响收盘前风险的事项、重大新证据、组合暴露和真实账户状态。14:30 不是固定决策/交易窗口；此前成熟的决策不应故意等到现在，也不得为了尾盘而强行交易。

## 20:30 — 深度研究、复盘与次日交接
完成白天未解决且仍重要的研究；复盘有学习价值的判断、交易和遗漏；核对执行状态并整理下一交易日可直接继续的 Active Context。

## 动态资本决策原则
- 08:45 / 09:27 / 09:40 / 10:30 / 11:15 / 13:30 / 14:30 都可能形成 NO ACTION、PROBE、BUY、ADD、HOLD、REDUCE、EXIT。
- 资本动作不绑定 Cron 时点。
- 持有周期不预设长期或短线，由每个 thesis 的 driver、证据有效期、预期差兑现速度和风险收益变化决定。
- 重大公告、thesis 证伪、风险突变、价格/成交异常或其他重要变化若在两个 Cron 之间被 Agent 实际获知，应当时重新评估。
- Cron 只能提供最低巡检频率，不能假装持续实时监控。更及时的响应依赖实际事件、消息或任务触发机制。
- 实际执行受 A 股交易时段、T+1、停牌/涨跌停、流动性、可卖数量、账户状态和当前交易工具真实能力约束。
- 20:30 主要用于研究、复盘和交接，不把非交易时段判断伪装成已执行交易。

## 为什么保留 8 个固定节点
这些节点覆盖隔夜、竞价、开盘确认、上午趋势形成、午前交接、午后重新定价和尾盘风险。它们是第一阶段实机运行的最低主动巡检框架。若未来接入可靠事件触发，应优先让事件触发补充两个 Cron 之间的重大变化，而不是无限增加轮询频率。

## 周末 — 周度复盘与研究议程
基于本周 daily memory、Active Context 和真实结果做周度复盘：检查发现质量、研究判断、组合管理、执行、Missed Opportunities 和重复错误；整理下周仍有效的 thesis、开放问题和研究优先级。
