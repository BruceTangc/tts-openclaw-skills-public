# A股投资 Agent 全天 Automations/Cron 设计

Cron 只负责**最低巡检频率**，不是买卖时间表，也不是「必须产出点什么」的闹钟。

**每个时点有且只有一个主任务（primary job）。** 主任务做完即止，不得为了填时间去做其他时点的工作。若本时点无增量信息且无到期 next_check，"安静退出"是合法且推荐的结果。

资本动作不绑定任何时点：任何时点只要新证据实质改变 thesis、赔率或组合风险，立即评估并行动；反之任何一个时点都可以是 NO ACTION。

---

## 时点职责表

| 时点 | 主任务（只做这一件） | 只此一家的独特职责 | 预期输出 |
|:--|:--|:--|:--|
| **08:45** | 恢复状态 + 隔夜增量 | **唯一**负责隔夜：公告、外围、产业、公司新闻 | 模板 A；无增量则一行 NO MATERIAL CHANGE |
| **09:27** | 集合竞价定价 | **唯一**看竞价：竞价价、竞价量、隔夜预期是否被修正 | 模板 A，且必须落到「竞价说明市场怎么想」 |
| **09:40** | 开盘现实验证 | **唯一**对比「竞价预期 vs 开盘现实」，验证 09:27 的判断对错 | 模板 A；必须明确写 09:27 判断成立/不成立 |
| **10:30** | 上午主线形成 | **唯一**负责发现当日新主线、异动板块、资金流向变化 | 模板 A（有异动才详写） |
| **11:15** | 上午收口 + 午间 handoff | **唯一**负责写 handoff：上午结论、下午要看什么 | 模板 A + Handoff |
| **13:30** | 午后重新定价 | **唯一**检查午间新增信息 + 上午主线的延续/反转 | 模板 A；必须写「上午判断是否延续」 |
| **14:30** | 尾盘风险 + 账户核对 | **唯一**必须做完 G1 账户核实；检查未了结的风险敞口 | 模板 B（如有动作）或模板 A |
| **20:30** | 深度研究 + 复盘 + 次日交接 | **唯一**负责研究、复盘、写次日 ACTIVE | 模板 D |
| **周末** | 周度复盘 | **唯一**负责周报 | 模板 E |

### 显式禁止

- 08:45 **不得**做深度研究（那是 20:30 的事）
- 09:27 / 09:40 **不得**重复 08:45 已经处理过的隔夜信息
- 10:30 / 13:30 **不得**重复写「市场观望情绪浓厚」这类没有事实支撑的判断
- 盘中任何时点 **不得**做超过 3 段新研究的深度工作（留给 20:30）
- **任何时点不得为了「今天还没动作」而强行 PROBE 或 BUY**

## 安静退出条件（硬判定）

**同时满足以下全部条件** → 只写一行 worklog，不做研究，不做输出：

1. 距上一个时点实际执行 ≤ 4 小时；
2. 持仓标的与候选标的自上轮以来**无价格变动 >3%**、无新公告；
3. ACTIVE 中**无 next_check 到期**；
4. 市场无重大突发（指数变动 >1%、政策/监管公告）。

worklog 只写：
```
### HH:MM — <cron>
NO MATERIAL CHANGE。下次关注：<next_check>
```

**不向用户推送**（安静原则）。

任一条件不满足 → 正常走该时点主任务。

---

## 必须推送的例外

以下情况**跳过安静退出**，立即处理并推送：

- 持仓标的触及证伪条件 → 模板 B
- 新出现 E1/R1 机会 → 模板 B（可 PROBE）
- 执行状态异常（部分成交/失败/在途不明）→ 模板 B
- 账户核实失败且影响持仓 → 模板 B（BLOCKED）

---

## 动态资本决策原则

- 08:45 至 14:30 任一时点都可能形成 NO ACTION / PROBE / BUY / ADD / HOLD / REDUCE / EXIT。
- 持有周期不预设长期或短线，由 thesis 的 driver、证据有效期、预期差兑现速度和风险收益变化决定。
- 两个时点之间实际获知的重大变化，应当立即重新评估，不等待下一轮。
- Cron 只提供最低巡检频率，不假装持续实时监控。
- 实际执行受交易时段、T+1、停牌/涨跌停、流动性、可卖数量、账户状态和工具真实能力约束。
- 20:30 只做研究、复盘、交接，不把非交易时段判断伪装成已执行交易。

## 为什么保留 8 个固定节点

覆盖隔夜、竞价、开盘确认、主线形成、午前交接、午后重定价、尾盘风险、晚间研究八个**互不重叠**的职责。若未来接入可靠事件触发，应优先用事件补充两点之间的变化，而不是增加轮询频率。

## 周末 — 周度复盘

基于本周 daily memory、ACTIVE 和真实结果做周度复盘：发现质量、研究判断、组合管理、执行、Missed Opportunities、重复错误；整理下周仍有效的 thesis、开放问题和研究优先级。
