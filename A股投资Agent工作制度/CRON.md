# A股投资 Agent 全天 Automations/Cron 设计

Cron 只负责**最低频率唤醒和时点目标**，不是买卖时间表。资本决策由市场事实、证据变化、组合风险和真实账户状态驱动。

所有时点遵循 AGENTS.md：恢复 ACTIVE → 读取增量 → 工作 → 固定模板输出 → Worklog → 更新 ACTIVE。

## 08:45 — 盘前恢复与隔夜变化
Prompt:
```
恢复投资 Active Context 和最近相关 memory，确认昨日未完成事项。检查自上次工作以来可能改变 thesis、组合风险或产生新机会的重大隔夜变化。需要当前事实时使用真实数据能力。若已经形成需要处理的资本问题，可立即评估，不等待下午。无重大变化则记录 NO MATERIAL CHANGE。完成后写 worklog 并更新 Active Context。
```

## 09:20 — 盘前关键验证
Prompt:
```
从当前 Active Context 继续，只检查盘前新增信息和开盘前必须确认的高优先级事项。不要重复 08:45 已完成研究。若新证据 materially 改变投资判断或组合风险，立即重新评估资本配置；时间点本身不是交易理由。完成后更新交接状态。
```

## 09:40 — 开盘后现实验证
Prompt:
```
继续今天已有工作。检查开盘后的市场反馈、价格/成交变化及新增事实是否验证或反驳现有 thesis。价格行为是证据之一，不能替代基本面因果。若资本条件已经改变，立即评估组合动作；不要等待 14:30。完成后记录增量并更新 Active Context。
```

## 11:15 — 上午收束与风险检查
Prompt:
```
恢复上午最新状态，处理真正改变判断的增量和最高价值未解决问题。检查 thesis 是否强化、削弱或证伪，以及组合是否出现需要上午收盘前处理的风险。若需要资本动作，现在即可评估；否则 NO ACTION。完成后更新 worklog 和 Active Context。
```

## 14:30 — 尾盘风险与未完成事项检查
Prompt:
```
从今天最新状态继续。检查仍未解决但可能影响收盘前风险的事项、当日新增重大证据、组合暴露和真实账户状态。14:30 不是固定决策或交易窗口；此前已经成熟的决策不应故意等到现在，此时没有新增优势也不得为了尾盘而交易。必要时评估资本动作，否则 NO ACTION。完成后记录理由并更新状态。
```

## 20:30 — 深度研究、复盘与次日交接
Prompt:
```
恢复今天完整投资上下文。完成白天未解决且仍重要的深度研究；对有学习价值的判断、交易或遗漏做必要复盘，区分决策质量与结果。只将经验证的 durable lesson 候选升级到长期记忆；普通日内流水留在 daily memory。核对当天已知执行状态，最后整理 Active Context，使下一交易日能够直接继续。
```

## 动态资本决策原则
- 08:45 / 09:20 / 09:40 / 11:15 / 14:30 都可能形成 NO ACTION、BUY、ADD、HOLD、REDUCE、EXIT 等资本判断。
- 资本动作不绑定 Cron 时点。
- 重大公告、thesis 证伪、风险突变或其他事件若在两个 Cron 之间被 Agent 获知，应当时重新评估，而不是等待下一个固定时点。
- Cron 只能提供最低检查频率；它不能保证发现两个时点之间所有市场事件。是否具备更及时响应能力取决于实际事件/消息/任务触发机制。
- 实际执行仍受 A 股交易时段、T+1、停牌、涨跌停、流动性、可卖数量、账户状态和当前交易工具能力约束。
- 20:30 主要用于研究/复盘/交接，不把非交易时段判断伪装成已执行交易。

## 为什么删除 13:30 和 15:10
13:30 与 11:15/14:30 容易产生低价值重复检查；15:10 的状态固化可由每轮强制 Worklog/ACTIVE 更新和 20:30 恢复承担。若实机证明存在收盘后立即 reconciliation 的刚性需要，再以证据恢复该节点。

## 周末 — 周度复盘与研究议程
Prompt:
```
基于本周 daily memory、Active Context 和真实结果做周度复盘：检查发现质量、研究判断、组合管理、执行、Missed Opportunities 和重复错误。区分随机结果与方法问题，提炼 Candidate/Durable lessons，并整理下周仍有效的 thesis、开放问题和研究优先级。不要因单一案例修改长期规则。
```
